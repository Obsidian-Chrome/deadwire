Mods

Les mods transforment l'apparence du bar avec une décoration cyberpunk immersive et ajoutent un distributeur de boissons 25th Hour personnalisé.

1

Installer le plugin Heliosphere

Assurez-vous d'avoir le plugin Heliosphere installé dans Dalamud. Ce plugin permet de gérer les mods et de recevoir les mises à jour automatiquement.

2

Télécharger les mods

Cliquez sur les liens ci-dessous pour installer les mods via Heliosphere :

25th Hour - Distributeur
Meuble de jardin personnalisé
Deadwire - Intérieur
Décoration intérieure du bar
3

Activer dans Penumbra

Les mods doivent être installés dans la collection Default de Penumbra pour fonctionner correctement.

Macro d'activation

Utilisez cette macro pour activer ou désactiver rapidement les mods du Deadwire :

/penumbra mod toggle Default | [HS] 25th Hour - Distributeur /penumbra mod toggle Default | [HS] Deadwire - Intérieur /penumbra redraw furniture ✓ Copié !

Note : Le distributeur 25th Hour étant un meuble de jardin, il faudra recharger la zone pour le voir apparaître / disparaître.

Plugin Pyonpix

Pyonpix permet d'afficher des contenus vidéo et images synchronisés sur les écrans TV du bar, créant une ambiance dynamique et partagée entre tous les visiteurs.

1

Ajouter le dépôt personnalisé

Ouvrez Paramètres Dalamud → Expérimental. En dessous de "Dépôts de plugins personnalisés", ajoutez l'URL suivante :

https://raw.githubusercontent.com/priprii/FFXIVPlugins/main/repo.json ✓ Copié !

Appuyez sur le bouton Sauvegarde en bas à droite.

2

Installer le plugin Pyonpix

Allez dans Plugins Dalamud → Tous les plugins. Cherchez Pyonpix et installez-le.

3

Configurer les options

Dans les options de Pyonpix, allez dans Shared Renderer Properties et décochez Source Alpha.

4

Se synchroniser

Dans Pyonpix, cliquez sur l'icône de chaîne pour récupérer votre clé d'authentification (liée au personnage, pas au compte).

5

Rejoindre le Discord Pyon

Cliquez sur l'icône d'étoile dans Pyonpix pour accéder au Discord de Pyon.

6

S'authentifier sur Discord

Sur le Discord de Pyon, allez dans le salon #pyonpix et authentifiez-vous avec votre clé.

7

Trouver et s'abonner aux Pyonpix du Deadwire

Appuyez sur la loupe dans Pyonpix pour rechercher des contenus. Rendez-vous à l'intérieur du Deadwire, puis triez par lieu et activez NSFW. Abonnez-vous aux Pyonpix du bar.
